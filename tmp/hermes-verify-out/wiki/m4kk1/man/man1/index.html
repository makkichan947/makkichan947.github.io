用户命令 (man1)

Shell 与常用命令

cat

名称

cat — 显示文件内容

概要

cat <文件>

描述

读取指定文件的内容并输出到标准输出。

示例

cat /export/cfg/passwd.db

显示用户数据库

参见

ls(1)、grep(1)、 …

echo

名称

echo — 输出文本

概要

  • -E — 禁用转义序列解释（默认）

id

名称

id — 显示用户身份信息

概要

id

描述

显示当前用户的 UID、GID、有效 UID/EUID、有效 GID/EGID 以及附加组列表。

参见

who(1)、passwd(8)、usermod(8)

2026-08-08

ls

名称

ls — 列出目录内容

概要

ls [路径]

描述

列出指定目录的内容。如果不指定路径，列出当前目录。

示例

ls

列出当前目录

ls /bin

列出 /bin 目录

参见

cat(1)、cd(1)、pwd(1)

ps

名称

ps — 显示进程状态

概要

ps

描述

显示当前系统中所有进程的信息，包括 PID、PPID、状态、名称。当前为单进程系统，仅显示 init 进程。

参见

who(1)、kill(1)

wc

名称

wc — 统计行、词和字符数

概要

wc [文件]

描述

统计指定文件或标准输入的行数、词数和字符数。

参见

grep(1)、cat(1)
