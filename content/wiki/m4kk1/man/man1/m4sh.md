## 名称

m4sh — M4KK1 Shell，交互式命令行解释器

## 概要

```text
m4sh
```

## 描述

M4SH 是 M4KK1 系统的 init 进程（PID 1），提供交互式命令行环境。支持命令执行、管道、重定向、环境变量、命令历史、Tab 补全。

## 命令行编辑

- **字符键** — 追加到命令行
- **Backspace / 0x7F** — 删除最后一个字符
- **Enter / 0x0D** — 执行命令
- **Tab** — 命令名补全
- **Up / Esc [ A** — 历史上一条
- **Down / Esc [ B** — 历史下一条
- **Ctrl+C** — 取消当前行
- **Ctrl+D** — 空行时退出 Shell

## 命令操作符

- `;` — 顺序执行
- `&&` — 前一命令成功则执行后一命令
- `||` — 前一命令失败则执行后一命令
- `|` — 管道（前一命令输出作为后一命令输入）

## 引号处理

- `'...'` — 逐字保留内容，不展开变量
- `"..."` — 保留内容，支持 `\"` `\\` `\$` 转义
- `\` — 转义下一个字符

## 环境变量

最多 16 个变量，每个最大 128 字节。导出语法: `export VAR=value`。展开语法: `$VAR` 和 `${VAR}`。
